Simulating autonomous mobile robot navigation inside a dense logistics warehouse. Utilizing **NVIDIA Isaac Sim 6.1.0** and **ROS 2 Jazzy** to evaluate real-time 2D LiDAR mapping, localization, and collision-free path planning through narrow storage aisles.

### Highlights
- **Physics Fidelity:** Modeled ground-wheel traction and sensor dynamics using PhysX in Isaac Sim 6.1.0.
- **2D SLAM & Mapping:** High-resolution occupancy grid generation using 2D planar LiDAR.
- **Autonomous Navigation:** Real-time trajectory generation and dynamic obstacle avoidance with Nav2.
